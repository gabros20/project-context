Portable core, thin edges

Adapters translate events. They do not own the memory.

Every host keeps its native skill syntax, trust model, and lifecycle capabilities. When a harness cannot actively continue a Stop boundary, project instructions and explicit skill invocation still work.

Install

From one command to shared memory.

The bootstrap fetches a pinned release, then the installer keeps one canonical personal copy, exposes it to detected harnesses, and safely merges project-scoped lifecycle adapters.

  • Pins version 0.4.0 by default
  • Preserves unrelated host settings
  • Backs up existing files before modification
  • Refuses malformed JSON instead of overwriting it

curl -fsSL https://project-context-mu.vercel.app/install.sh | sh
