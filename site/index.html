What you get

What project-context gives you.

No service to run and no transcript collector watching every command. It is a file, a CLI, and optional adapters for the agent tools you already use.

01

Switch tools mid-project

Claude Code can leave a handoff that Codex, Cursor, Pi, or another supported agent can read later.

02

Save decisions and failed attempts

Save why a decision was made, which approach failed, what the tests proved, and what still needs work.

03

Write only at useful moments

The default setup writes nothing automatically. Invoke the skill after a milestone or before changing agents.

04

Find notes by scope or file

Ask for the authentication notes or everything related to one source file. The agent does not need to load the full log.

05

Use plain local files

The runtime needs Python and Git. Memory is JSONL that you can inspect, version, ignore, or synchronize yourself.

06

Load notes at session start

Optional hooks can load notes at session start and remind an agent to checkpoint. They never call a model in the background.

What runs in a session

It does not write after every prompt.

The default setup is manual. Hooks are optional, and hooks never generate notes on their own.

Token and latency budget

Stored notes cost nothing until an agent reads them.

Hooks use local Python, Git, and file operations. No background model runs. The limits below are prompt caps, not recurring charges.

Large repo note. With hooks installed, turn-start currently runs git status --untracked-files=all for each submitted prompt, even when the checkpoint gate is off. Use skill-only mode if you want the lowest possible per-turn overhead.

Install

Install the skill in one command.

This installs the skill and the ctx command. It does not turn on hooks. Initialize each repository where you want shared notes, then add hooks later if you want them.

  • Pins version 0.4.0 by default
  • No hooks unless you ask for them
  • Checkpoint enforcement starts off
  • Preserves unrelated host settings
  • Backs up files before changing them
macOS / Linux
curl -fsSL https://project-context-mu.vercel.app/install.sh | sh
